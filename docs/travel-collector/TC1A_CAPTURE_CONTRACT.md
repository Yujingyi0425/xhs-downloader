# TC1A：CollectionPageMeasurement Contract

本契约只接受真实页面测量证据。当前尚未访问 Japan 收藏夹页面，所有字段保持 `UNKNOWN`；`UNKNOWN` 不得被 TC1B 当作事实硬编码。

```text
PAGE_DETECTION=UNKNOWN
SCROLL_CONTAINER_STRATEGY=UNKNOWN
CARD_DISCOVERY_STRATEGY=UNKNOWN
FEED_ID_EXTRACTION=UNKNOWN
XSEC_TOKEN_EXTRACTION=UNKNOWN
TITLE_EXTRACTION=UNKNOWN
AUTHOR_EXTRACTION=UNKNOWN
NOTE_TYPE_EXTRACTION=UNKNOWN
COVER_EXTRACTION=UNKNOWN
VIRTUALIZATION_MODEL=UNKNOWN
LAZY_LOAD_MODEL=UNKNOWN
STOP_CONDITION_MODEL=UNKNOWN
```


## 冻结规则

只有在脱敏真实页面证据确认页面身份、滚动容器、卡片发现、feed_id、token 存在性、虚拟化、lazy-load、结束信号以及数量相等后，才能把对应字段从 `UNKNOWN` 改为 `FACT` 并提交 TC1A Gate。当前不冻结 selector，不实现 Capture Engine。
